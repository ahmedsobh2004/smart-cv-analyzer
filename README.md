# 📄 CV Analyzer Pro | محلل ومقيم السير الذاتية بالذكاء الاصطناعي

تطبيق ويب تفاعلي واحترافي مبني باستخدام **Python** و **Streamlit** و **Gemini AI** لتحليل السير الذاتية (CV / Resume) وتدقيقها وفق المعايير القياسية العالمية لأنظمة التوظيف الإلكترونية (**ATS - Applicant Tracking Systems**).

---

## 🌟 الميزات الرئيسية (Features)

1. **فحص توافق الـ ATS (ATS Compatibility Score 0-100)**:
   - قياس اكتمال الأقسام الأساسية (ملخص، خبرات، تعليم، مهارات، مشاريع).
   - رصد معلومات التواصل المهنية (Email, Phone, LinkedIn, GitHub).
   - تقييم الطول وعدد الكلمات وتناسق التنسيق.

2. **مطابقة الوصف الوظيفي (Job Description Matching & Skill Gap)**:
   - حساب نسبة التطابق (Match %) بين سيرتك الذاتية وأي إعلان وظيفي مستهدف.
   - كشف المهارات والكلمات المفتاحية المفقودة (Missing Skills).

3. **تدقيق صياغة الإنجازات ومعايير STAR (STAR Method & Action Verbs)**:
   - كشف النتائج الرقمية والنسب المئوية (`%`, `$`, مقاييس حجم العمل).
   - رصد الأفعال القوية (Power Action Verbs) والتحذير من العبارات الضعيفة والتقليدية (Passive Phrases).
   - **أداة تفاعلية لإعادة صياغة النقاط (Bullet Point Rewriter)** لتحويل أي نقطة عادية إلى 3 صياغات قوية.

4. **تصنيف المهارات الذكي (Skills Taxonomy)**:
   - تصنيف تلقائي للمهارات: لغات البرمجة، أطر العمل، قواعد البيانات، الكلاود والـ DevOps، والمهارات الشخصية (Soft Skills).
   - رسوم بيانية تفاعلية (Plotly Charts).

5. **المستشار المهني بالذكاء الاصطناعي (AI Career Coach - Gemini)**:
   - يعمل بوضعين: **مباشر** عبر Google Gemini 2.5 Flash أو **خوارزمي مجاني مدمج** بدون الحاجة لمفتاح API.
   - تحليل SWOT للمرشح، وأبرز نقاط القوة، وأسئلة مقابلات شخصية متوقعة مخصصة لملفك.

6. **تصدير التقرير (Export Audit Report)**:
   - تصدير تقرير التدقيق بنقرة واحدة كملف Markdown.

## 🚀 طريقة التشغيل السريعة (Quick Start)

### 1. تثبيت المتطلبات (Requirements)
```bash
cd C:\Users\sobhi\.gemini\antigravity\scratch\cv-analyzer
python -m pip install -r requirements.txt
```

### 2. تشغيل التطبيق (Run Streamlit App)
```bash
streamlit run app.py
```

سيفتح التطبيق تلقائياً في المتصفح على العنوان: `http://localhost:8501`

## 🔑 استخدام Gemini API (اختياري)
التطبيق مجهز ليعمل ذاتياً بدون أي إعدادات إضافية. وإذا أردت تفعيل الذكاء الاصطناعي الحي من Google:
1. احصل على مفتاح مجاني من [Google AI Studio](https://aistudio.google.com/).
2. أدخل المفتاح في الحقل المخصص في القائمة الجانبية للتطبيق أو اضبط المتغير البيئي `GEMINI_API_KEY`.
